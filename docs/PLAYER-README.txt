POLYEC — ĐẠI BÀN CỜ VƯƠNG QUYỀN
Bản trình bày M0a · Windows x64 · 14/10/2026

CÁCH MỞ
Giải nén toàn bộ thư mục, rồi mở PolyEc.exe.
Giữ PolyEc-runtime.exe, PolyEc-runtime.pck và thư mục bin cạnh launcher.
App chạy offline, không cần cài Godot, Python, Node hay API key.

TRÌNH BÀY NHANH (KHOẢNG 1 PHÚT)
1. Chọn Thanh Điền và Hắc Sơn để xem hồ sơ thay đổi.
2. Cuộn để thu/phóng; kéo chuột giữa/phải để di chuyển.
3. Nhấn Tiếp tục hoặc Space; quan sát ngày tăng, thử 2x/4x.
4. Tạm dừng và kiểm tra ngày đứng yên.
5. Mở F1 để xem sổ tay. Đóng sổ tay vẫn giữ tạm dừng.
6. Rời cửa sổ rồi quay lại: thế giới vẫn tạm dừng, không chạy bù.
Home / Toàn cảnh đưa bản đồ về vị trí ban đầu.

PHẠM VI
Đây là prototype nền tảng native: bản đồ hai lãnh địa, chọn/pan/zoom,
hồ sơ, đồng hồ, tốc độ và pause. Địa hình và mô tả là dữ liệu thử nghiệm.
Chưa có kinh tế, chính trị, chiến dịch, save game hoặc NPC dùng RL.
Chỉ bản Windows đã được build và kiểm tra; Linux chưa được xác minh.

CÔNG NGHỆ & GHI NHẬN
Godot 4.5.1, godot-cpp 4.5, C++20 simulation core.
Font Be Vietnam Pro và Newsreader. Giấy phép thư viện có trong licenses/.
Model OpenCode hỗ trợ phát triển; game không gọi model hay dịch vụ mạng.
