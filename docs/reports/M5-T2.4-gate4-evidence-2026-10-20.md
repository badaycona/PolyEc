# M5 T2.4 Gate 4 — Establishment production evidence

## Decision and scope

Gate 4 implements the reviewed [production plan](../design/M5-T2.4-gate4-production-plan.md): daily, Realm-owned production for Cloth, Tools, and MilitarySupply workshops; sparse actor/site work-unit watermarks; shortage/capacity forfeiture; timeline-aware legacy recipe suppression; and save schema 14 with `ESTABLISH_3`.

The planner is stateless and stages recipe, stock, watermark, production-day, and aggregate ledger deltas. Realm validates the staged read set and checked arithmetic, prepares a complete Establishment vector, then publishes stock/watermark/marker and goods-ledger changes together. Production uses the existing 16-tick work unit and does not create an input-transfer command, alter action/observation/reward/model shape, or claim learned-policy integration.

Schemas 12–13 migrate site watermarks from saved site attendance and set the production-day marker to the loaded Realm day. Schemas 7–11 have no site attendance and retain empty watermarks; existing no-site saves create no establishments. A timeline-off world retains the legacy Cloth/Tools pilot. With the timeline enabled, only the matching industry suppresses its corresponding regional pilot; monthly unrest behavior remains.

## Review

Review was performed by the implementing Codex in a separate audit pass after implementation. No separate fresh reviewer was used. The audit checked the planner, Realm commit/revalidation, schema reader/writer, migration path, conservation invariant, and failure atomicity. Hand-calculated recipe tests, legacy timeline compatibility comparisons, save/load continuation and migration fixtures, malformed-save rejection, and full Release/Debug CTest served as the implementation oracles. This is a self-review limitation, not an independent external review claim.
