## Implemented behavior

- **Typed activity**: `ActivityKind { Generic=0, Work=1 }` plus `int region` appended to `ActivitySession` and `ScheduleCommand` (tail-appended to preserve existing aggregate initializers). `Submit` copies `kind`/`region` into the session.
- **Atomic submit validation**: validation runs before any state change. Unknown `kind` is rejected; `Work` requires `region ∈ [0, regions_]`; `Generic` requires `region == -1`. Rejects leave fingerprint, sessions, counters, and cursor unchanged.
- **Presence predicate**: `present(a) = person(a).alive && person(a).destination == -1 && person(a).region == session.region`. `destination` is compared strictly to `-1`; negative values other than `-1` are invalid and never credited. `busy_until` is deliberately excluded from the predicate.
- **Unique tick union**: per chunk, credit is the length of the union of clipped half-open intervals of active `Work` sessions for the actor, so overlapping sessions count once per actor per tick, never summed. Interval-union helper is private in `realm.cpp`.
- **Sparse counter**: `ScheduleBook::work_present_ticks` maps actor → cumulative ticks; only positive entries are stored. Invariant: entries only when `timeline_contract == true`, actor in range, `0 < ticks <= cursor`.
- **Save**: `POLYEC_REALM_8` / `SCHEDULE_2` adds session `kind`/`region` and an attendance count plus sorted `actor tick` records (serialized by ascending actor ID for stable bytes). Save is deterministic across repeated serialization.
- **Migration**: magic-branched load — `POLYEC_REALM_7` / `SCHEDULE_1` reads the legacy layout and defaults sessions to `kind=Generic`, `region=-1`, empty attendance; re-serialization produces v8.
- **Python binding**: `schedule_command` gains optional trailing `kind=0, region=-1`; `schedule_sessions` reports read-only `kind`/`region`; `work_present_ticks(actor)` is a read-only accessor. No writer exists — mutation stays behind the Realm command path.
- **Unchanged**: action/`Intent`/mask/legality, observation, `realm_obs`/`realm_state`, `model_contract`, bundle/training, `day_production`/`day_payroll`.

## Test coverage added

- Typing round-trip and atomic reject of unknown kind, bad regions, and negative region.
- Overlap credited once via union; region mismatch, travel (`destination != -1`, including invalid `-2`), and dead actor credit zero.
- Union ≤ chunk, total ≤ cursor; chunk splits match a one-shot advance by fingerprint.
- v8 deterministic round-trip; v7 → v8 migration defaults to Generic/-1 with empty attendance; corrupt attendance/kind/timeline guards rejected; zero attendance normalized away.
- Mid-day save/restore/continue equivalence covered by the C++ schedule tests and the Python binding replay.
