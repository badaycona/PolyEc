# Hướng dẫn cố định theo gói phát hành thử

Hướng dẫn người chơi hiện hành là [PLAYER_GUIDE](../PLAYER_GUIDE.md), viết bằng ngôn ngữ người chơi.

Các file `PLAYER-README*.txt` trong thư mục này là bản hướng dẫn của gói prototype/RL/M3/M4 tương ứng. `scripts/package-windows.ps1` đọc đúng bản khi đóng gói. Giữ chúng để không đánh tráo tính năng giữa các build và không làm hỏng package. Chúng không là spec gameplay hoặc kế hoạch coding hiện hành; bản build cũ chỉ có các tính năng ghi trong README đi cùng.
