## Kế tiếp sau nhóm đang làm

1. Chọn tiếp nhóm M5 còn thiếu từ `IMPLEMENTATION_PLAN.md`, trước mắt là luật kết thúc chiến dịch chiếm đóng. Tù binh/đầu hàng/đình chiến cần plan riêng vì đối tác hiện không có quân đội mô phỏng bằng cá thể có thể thành tù binh. Plan phải quy định quyền, consent, phản hồi từ chối, save/load và giới hạn world model.
2. Tiếp tục terrain/passability tác động đường đi, thành viên/bầu cử hội đồng, nhu cầu nội địa còn thiếu, chuỗi cung cầu dài và tích hợp game/app; sau đó kiểm Profile B, balance, stress/long-run, performance và package. Không hạ scope.
3. Sau các nhóm gameplay, chạy mốc tích hợp M5: C++/Python/GDExtension/Godot, Profile B, long-run, learned-policy gates, hiệu năng và Windows package. Chỉ dùng source/run tương ứng để xác nhận.
4. Khi M5 hoàn tất, làm core refactor R1–R4 theo `IMPLEMENTATION_PLAN.md`, mỗi phần có plan/evidence và kiểm tra phụ thuộc.
5. Chỉ sau M5 và R1–R4 mới lập dataset từ C++ core hiện hành, huấn luyện và đánh giá RL. Mỗi run lưu dữ liệu nguồn, manifest, biểu đồ đúng run và seed split train/validation/holdout; báo cáo phải giải thích cách tạo dữ liệu và từng trường/nhãn.
