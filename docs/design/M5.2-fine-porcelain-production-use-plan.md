# M5.2 — FinePorcelain production and personal use

Status: implemented and checked; see evidence report below. The chosen values remain a gameplay trial and have not been shown balanced.

## Baseline and scope

Baseline before this group: `realm-v39`, save72, household/config and timeline/config v50, 382 state values,400 candidate actions,5,182 observation values and reward v14. After this group: `realm-v40`, save73 and config v51; tensor sizes and reward remain unchanged. Atlas region15 has public PotteryKiln industry13, which makes Pottery28 from its finite clay source, Fuel and Work. FinePorcelain25 now has a separate finishing producer and hosting use. GeneralLuxury26 remains a separate later item.

Implement a new `FinePorcelainWorks` industry ID24 in region15. It is an additional finishing workshop, not a replacement for PotteryKiln and not an alias for Pottery. One Pottery and one Fuel plus24 Work ticks create one FinePorcelain. The output returns to regional stock, can be bought through the existing market order, and is used by a personal high-end hosting action.

## Implementation result

Implemented `FinePorcelainWorks` industry24 in region15 with recipe 1 Pottery +1 Fuel +24 Work ticks →1 FinePorcelain. Personal social action slot30 is available to an eligible adult Civilian with personal stock and12 coins; it consumes one item, pays the region fund, adds18 personal social points up to100 and occupies7 game days. Candidate slots are270–272 and municipal slots279–281. The UI explains both recipe inputs/output and the hosting conditions/effect.

The first candidate implementation reused slots267–269 and overwrote PotteryKiln; the existing mapping showed these were occupied, so the final implementation uses offset+6. The first schema73 roundtrip was also rejected by the schedule reader's upper bound72; the reader bound now accepts73 because its section format is already stable beyond schema34. The test fixture initially passed different bundle names to serialize and deserialize; the names now match.
