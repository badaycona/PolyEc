# M5.5 — chẩn đoán phase thời gian ngày của native benchmark

Ngày 2026-10-21. Lát đo chẩn đoán để chọn điểm tối ưu tiếp theo; không tự thay mục tiêu latency hoặc gọi là profile B acceptance.

## Phạm vi

- `core/src/realm.cpp`: build option `POLYEC_ENABLE_REALM_PHASE_PROFILE` bật bộ đếm compile-time quanh 14 phase `RealmDayPipeline`; default OFF, nên build sản phẩm không có timer hoặc thay đổi layout.
- `native/realm_runtime.cpp`: cùng build option phân rã mỗi ngày thành role-sync/due, observation pack, ONNX inference, action revalidate/commit, Realm advance, memory resize/role sync và full invariant check.
- `native/realm_benchmark.cpp`: trong mỗi lời gọi `RealmRuntime::advance(1)`, lấy delta `inference_ms()` trước/sau làm thời gian policy ONNX của ngày đó. Giữ bộ đo wall time quanh cùng lời gọi; serialize tổng nanoseconds theo phase và component.
- Báo p50/p95/max riêng cho full day, inference, và phần còn lại `max(0, full_day - inference)`; xuất đủ metrics vào JSON để phân biệt chi phí policy, decision preparation, Realm phase và invariant.
- Không sửa Runtime, C++ core, gameplay, random stream, model, training, save, action/observation/reward hoặc nhãn quality. Không dùng số này để kết luận chất lượng learned policy.

## Gate

1. Build Release `polyec_realm_benchmark`.
2. Chạy cùng ba v7 pilot models, seed37, 31 ngày, 100k người, cả 128 và 512 complex actors. Lưu JSON mỗi run và xác nhận các thành phần latency khớp relation đầy đủ theo từng ngày, `money_conserved=true`, `invariant=true`, route shock chạy, manifest R1 vẫn false.
3. Chạy đường benchmark mặc định 10k để xác nhận output cũ vẫn hợp lệ, kiểm JSON parse và scoped `git diff --check`.

Self-review; không có reviewer độc lập. Đây là diagnosis, không phải tối ưu hóa hoặc hoàn tất M5.5.
