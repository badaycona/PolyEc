# CURRENT_TASK — hoàn thiện gameplay M5 trước RL

Cập nhật: 2026-10-25. Mục tiêu theo yêu cầu người dùng: hoàn tất toàn bộ base M5, tiếp đó hoàn tất core refactor R1–R4, rồi mới tạo dữ liệu và chạy RL. Không đặt tiến độ theo giờ; khi đóng một nhóm, tự chọn điều kiện thiếu tiếp theo và tiếp tục cho tới khi người dùng yêu cầu dừng. Được tự quyết định luật/setting gameplay hợp lý và ghi rõ phiên bản, đơn vị, miền hợp lệ, lý do, phép kiểm. Mọi artifact/model/run không thuộc nhóm đang làm trong workspace phải được giữ nguyên.

## Phạm vi kiểm

Mỗi sửa C++ nhỏ: build target liên quan và chạy test hành vi, reject nguyên tử, biên bị tác động. Khi đóng nhóm core: kiểm command → transaction → ngày game → save/load bằng C++, cộng hồi quy phần phụ thuộc. Chỉ build/check Python, native, GDExtension, Godot khi API hoặc bề mặt gọi bị đổi hoặc tại mốc chức năng ổn định. Không mặc định ALL_BUILD/full CTest sau từng sửa; trước khi tuyên bố game/M5 hoàn tất vẫn phải chạy kiểm tích hợp, learned policy, performance, stress và package theo roadmap. Không train RL trước gameplay.
