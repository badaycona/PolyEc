## Files changed

- `core/src/realm_clock.cpp`: `update` now captures the Pause result and throws `std::runtime_error("clock pause failed")` before mutating accum/seen revision/cursor when Pause fails.
- `core/tests/test_realm_clock.cpp`: added core Pause/Resume overflow reject tests and controller overflow regression tests; check count moved from 170 to 231.
- `docs/design/M5-T1b1-realm-clock-plan.md`: explicit approved failure semantics for long-gap update.

## Failure semantics

- Normal long gap: Pause succeeds, accum is dropped, returns false.
- Already-paused core at `UINT64_MAX`: Pause is idempotent success, accum dropped, returns false.
- Unpaused core at `UINT64_MAX`: Pause fails; update throws `std::runtime_error("clock pause failed")` with no mutation to accum, seen revision, cursor, or paused state.
- Core `execute(RealmClockCommand)` Pause/Resume overflow returns `RealmResult{false, "Pause revision overflow"}` and leaves serialized state unchanged.
