# M5 T3.1 — persistent body state

Ngày 2026-10-21. Accepted sau Codex self-review; không có reviewer độc lập. Plan: [T3.1 body-state persistence](../design/M5-T3.1-body-state-persistence-plan.md).

## Kết quả

Thêm `Person::body_state` với hai thang nguyên độc lập `sleep_debt` và `exertion`, mỗi thang từ 0 đến 100; `health` và attention giữ nguyên nghĩa hiện tại. State mặc định bằng 0. Save mới là `POLYEC_REALM_18`, mang phần sparse `BODY_1` sau `WORKCREDIT_1`; schema 7–17 giữ nguyên grammar cũ và migrate state mới thành 0. Loader stage record, kiểm actor tăng dần, giá trị, record zero dư và count trước khi publish; Realm invariant cũng kiểm cận.

Python `person(id)` expose hai trường chỉ đọc. Không đổi observation, reward, action, model contract, UI hoặc luật gameplay. Lát này chưa có command cập nhật state; đây là nền lưu trạng thái, chưa phải chuyển trạng thái/chăm sóc/hồi phục/công sức.

Schema mới nằm ở section riêng thay vì kéo dài mỗi Person row, để giữ stride và offsets của các save/migration fixture 7–17. `BODY_1` chỉ lưu record khác 0 theo Person ID tăng dần.
