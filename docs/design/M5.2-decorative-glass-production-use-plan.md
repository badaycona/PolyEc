# M5.2 — DecorativeGlass: sản xuất và sử dụng cá nhân

Trạng thái: đã chọn làm nhóm tiếp theo sau Livestock.  
Mục tiêu: đưa GoodId DecorativeGlass (24) vào chuỗi chơi thật, giữ PlainGlass (27) hiện có độc lập, cho hàng hoàn thành vào kho vùng và thị trường, rồi nối một consumer cá nhân qua command/transaction C++ hiện hành.

## Baseline

Đọc và giữ nguyên: `docs/CURRENT_TASK.md`, source contract hiện tại `realm-v38`, save schema71, household/config và timeline/config v49, 382 state values,400 candidate actions,5.182 observation values, reward v14. Atlas region10 có Glassworks ngành12 tạo PlainGlass từ Fuel và source hiện hành. Save schema chỉ tăng khi ghi thêm ngành mới; save cũ phải tiếp tục nạp đúng.

## Luồng phải hoàn thành

`Glassworks → Work → PlainGlass kho xưởng → kho vùng → transfer vào DecorativeGlassWorks → Fuel + quyền/lịch Work → DecorativeGlass → kho vùng → market order buy → inventory cá nhân → social consumer → save/load`.

Core C++ thêm industry/source mapping, recipe hai input, candidate/create guard region10, production preview, save schema72, invariants và test riêng. Godot cho biết rõ output, hai input, Work, kho và nguồn; mô tả action ghi item/tiền/lợi ích/tuổi/thời gian. Python/native gọi cùng core; không viết luật riêng.
