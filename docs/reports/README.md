# Evidence theo revision và workload

Đây là báo cáo những lệnh/kiểm tra đã chạy, không phải plan hiện hành. Đọc [CURRENT_TASK](../CURRENT_TASK.md) để biết gì đang được làm và [HISTORY](../DEVELOPMENT_HISTORY.md) để xem diễn tiến.
