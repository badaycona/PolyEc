# M5 T3.2 — actual Rest time and sleep debt

## Goal

Make `Intent::Rest` reserve actual game time and change body state only as that time elapses. Preserve exact pause, day-split and save/load behavior. Do not infer exertion from attendance: P6 separates presence, attention and effort.

## Working gameplay contract

- A Rest command begins at the Realm cursor and ends at the start of `day + term`, matching the existing `busy_until` deadline. The interval is `[begin_tick,end_tick)` and records its home region.
- For each completed game day, one full day without Rest adds one `sleep_debt` day-equivalent; one full day resting removes one. Partial days add/subtract exact `ticks/64` using a signed remainder in `[-63,63]`. Clamp debt to `[0,100]` and clear outward remainder at either clamp. This is an abstract game-time balance, not hours or a medical scale.
- The existing Rest health benefit (+15 when nutrition is at least 40) occurs once, only when the committed interval completes. Rejecting, pausing, saving or loading does not grant it early or twice. If the actor dies or leaves the recorded region, no Rest credit is accrued for that time.
- Typed Work intervals cannot overlap an active Rest interval. Generic low-attention activity may overlap Rest.
- No health penalty from debt and no exertion update from attendance are introduced here. Work effort needs a delivered-attention/effort contract.
