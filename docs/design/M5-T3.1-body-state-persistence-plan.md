# M5 T3.1 — persistent body state

## Goal

Add explicit, bounded per-person sleep-debt and exertion state as the foundation for T3 body transitions. This slice does not claim to implement recovery or work effort; those transitions need actual rest/work time and a separately checked contract.

## Contract

- `health` remains the existing health measure. `sleep_debt` and `exertion` are distinct integer scales in `[0,100]`; higher values mean more debt/exertion. New persons and migrated saves start at zero.
- State is owned by `Person`, serialized in the Person section, preserved by copy/save/load, exposed read-only to Python, and included in Realm invariants.
- Invalid values reject save load before publishing a world. Existing save schemas 7–17 migrate to zero; new saves use schema 18. The schema-specific inventory migration and all unrelated section formats remain unchanged.
- No command directly edits these values in this slice. A later T3 transition slice will update them only from actual game-time activity, with pause producing no recovery.
- No reward, observation shape, model contract, UI, or gameplay decision changes here.

## Files and ownership

- `core/include/polyec/realm.hpp`: `BodyState` value owned by `Person`.
- `core/include/polyec/person_section_codec.hpp`: append/read the two fields for schema 18; default old saves to zero.
- `core/src/realm.cpp`: schema bump, load dispatch and invariant bounds.
- `bindings/python/realm_binding.cpp`: read-only person projection.
- `core/tests/test_realm.cpp` / existing save fixtures: round-trip and migration/rejection checks.
- `ai/tests/realm_clock_binding_checks.py`: verify Python projection and save/load parity.

## Risks / limits

The scale is a storage contract, not a physiological formula. It does not infer time units or approve balance. This slice must not be cited as completion of T3, care, sleep, or effort.
